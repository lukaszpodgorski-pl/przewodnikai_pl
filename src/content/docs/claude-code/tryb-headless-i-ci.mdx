:::

Podstawa to `claude -p "prompt"` - uruchamia pełną pętlę <Termin id="agent-ai">agentową</Termin> (Claude sam przechodzi kroki: zaplanuj → użyj narzędzia → sprawdź wynik → wybierz następny krok, aż skończy), ale bez okna rozmowy: wypisuje wynik i kończy działanie. Dzięki temu możesz go wpiąć w skrypt albo w CI (ciągłą integrację, ang. _continuous integration_ - automat, który po każdej zmianie w repozytorium sam uruchamia testy i inne sprawdzenia).

Przykłady na tej stronie są w składni basha (macOS, Linux, WSL albo Git Bash na Windows).

```bash
claude -p "przeanalizuj błędy testów" --output-format json --max-budget-usd 2.00
cat logs.txt | claude -p "wyjaśnij te błędy"
git diff | claude -p "przejrzyj te zmiany"

# łańcuch przez stream-json:
claude -p --output-format stream-json "pierwsze zadanie" | \
  claude -p --input-format stream-json --output-format stream-json "przetwórz wyniki"
```

**Formaty wyjścia.** `text` domyślnie. `json` daje jeden obiekt z metadanymi: koszt, czas, liczba tur, `session_id`. `stream-json` wypisuje na bieżąco wiele obiektów JSON, po jednym w linii (format NDJSON), i wymaga `--verbose`. Flaga `--json-schema '{...}'` wymusza walidowane wyjście według schematu.

**Do CI** używaj `--allowedTools` albo `--permission-mode dontAsk`, żeby nie blokować się na promptach, oraz `--bare` dla szybkich i powtarzalnych uruchomień: Claude Code pomija wtedy automatyczne wczytywanie hooków, skilli, pluginów, serwerów MCP i CLAUDE.md (docelowo ma to być domyślne dla `-p`). Uwaga: ten tryb nie używa logowania subskrypcją. Wymaga klucza `ANTHROPIC_API_KEY` z Claude Console, czyli rozliczenia przez API (dostęp do modelu dla programistów, bez okna czatu).

Kody wyjścia: 0 to sukces, każda inna wartość to błąd. Dodatkowo sprawdzaj `is_error` w JSON - to nie jest to samo.

**Sesje w skryptach:**

```bash
session_id=$(claude -p "..." --output-format json | jq -r '.session_id')
claude -p "..." --resume "$session_id"
```

## Agent SDK

Ten sam silnik jako biblioteka. Pakiety: `claude-agent-sdk` dla Pythona i `@anthropic-ai/claude-agent-sdk` dla TypeScriptu. Oba zawierają Claude Code, więc zwykle nie trzeba go instalować osobno.

```typescript
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Napraw błąd logowania",
  options: { model: "claude-sonnet-5-5", maxTurns: 5 }
})) {
  console.log(message);
}
```

:::caution[Rozliczenie headless SDK]
Agent SDK i `claude -p` na planach subskrypcyjnych korzystają z tych samych limitów co reszta subskrypcji. Zapowiadaną na 15 czerwca 2026 zmianę rozliczenia wstrzymano. Od 7 października 2026 plany Max, Ultra i Team mają dodatkowo miesięczne kredyty API. Obejmują one Agent SDK i `claude -p` tylko wtedy, gdy używasz ich z kluczem API z podpiętej organizacji Console - po zalogowaniu planem nic się nie zmienia ([Claude Help Center](https://support.claude.com/en/articles/15036540)). Do CI i CD używaj headless CLI (`claude -p`), a SDK wtedy, gdy osadzasz pętlę we własnym programie.
:::

## Ćwiczenie: 10 minut

1. Napisz jednolinijkowiec: `git diff | claude -p "Wypisz potencjalne bugi jako listę" --output-format json`.
2. Jeśli nie masz jeszcze `jq` (lekcja o [hookach](/claude-code/hooks/)), zainstaluj je - to małe narzędzie do wyciągania pól z JSON-a, do pobrania z jqlang.org.
3. Wyciągnij z odpowiedzi `session_id` i koszt: dopisz na końcu jednolinijkowca `| jq -r '.session_id, .total_cost_usd'`.

**Zaliczenie:** masz działający potok, który przyjmuje diff i zwraca strukturę danych. To jest szkielet każdej automatyzacji, którą zbudujesz później.

**Jeśli nic nie zgrzyta i zostaje czas:** dodaj `--max-budget-usd 0.10` i sprawdź, co się dzieje, gdy zadanie przekracza budżet. Lepiej zobaczyć to teraz niż na produkcyjnym pipeline.

## Teraz wiesz

- `-p` to pełny agent bez interfejsu, gotowy do wpięcia w skrypt albo pipeline.
- W CI ustawiasz uprawnienia z góry i sprawdzasz `is_error`, nie tylko kod wyjścia.
- CLI do automatyzacji, SDK do osadzania we własnym programie.

**Następny krok:** [Kontekst i koszty](/claude-code/kontekst-i-koszty/) - najważniejszy zasób w tej pracy i sposoby, żeby go nie przepalać.
