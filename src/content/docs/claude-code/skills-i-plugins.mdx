## Agent Skills

Skill to instrukcja dla Claude zapisana w pliku `SKILL.md` w osobnym folderze - na przykład "jak piszemy commity w tym projekcie". Plik zaczyna się od frontmattera (bloku ustawień, m.in. nazwy i opisu - patrz [Własne komendy](/claude-code/wlasne-komendy/)), a pod nim jest zwykła treść. Skill ładuje się stopniowo (_progressive disclosure_), w trzech poziomach:

1. Zawsze załadowane są tylko `name` i `description` - kilkadziesiąt tokenów.
2. Pełna treść `SKILL.md` ładuje się, gdy Claude uzna skill za istotny albo gdy wpiszesz `/skill-name`.
3. Pliki pomocnicze (REFERENCE.md, skrypty) ładowane są dopiero na żądanie.

```markdown
---
name: architecture-diagram
description: Use this when generating architecture or system diagrams
allowed-tools: Read, Grep
---
Używaj formatu Mermaid. Zaznacz granice usług, kierunek przepływu danych,
zależności zewnętrzne.
```

Skill projektu zapisujesz w `.claude/skills/<nazwa>/SKILL.md`, a skill dla siebie, działający we wszystkich projektach - w `~/.claude/skills/<nazwa>/SKILL.md`. Najważniejsze pola frontmattera: `description` (po nim Claude poznaje, kiedy użyć skilla - to jedyne zalecane pole), `name`, `allowed-tools` (narzędzia, których Claude może użyć bez pytania o zgodę) i `disable-model-invocation: true` (skill uruchomisz tylko Ty, ukośnikiem).

Skill jest jednocześnie komendą: `.claude/skills/deploy/SKILL.md` wywołasz jako `/deploy`. Dawne własne komendy z `.claude/commands/` zostały ze skillami scalone - zobacz lekcję [Własne slash commands](/claude-code/wlasne-komendy/).

Skille to domyślna jednostka reużywalnej wiedzy działająca **w głównym <Termin id="okno-kontekstowe">kontekście</Termin>** - w odróżnieniu od [subagentów](/claude-code/subagenci/), którzy mają kontekst osobny. To jest właściwe kryterium wyboru między jednym a drugim.

## Plugins i marketplace'y

Plugin to paczka, która instaluje naraz kilka rozszerzeń: skille, subagentów, hooki i serwery MCP. Marketplace to katalog pluginów - repozytorium z listą paczek i adresami, skąd je pobrać. Oficjalny marketplace Anthropic (`claude-plugins-official`) Claude Code dodaje sam przy pierwszej sesji w terminalu. Plugin działa z Twoimi uprawnieniami, więc instaluj tylko z zaufanych źródeł.

```text
/plugin                                  # menu pluginów
/plugin marketplace add owner/repo       # tylko dla innych marketplace'ów
/plugin install code-review@claude-plugins-official
/reload-plugins                          # po instalacji z shella, bez restartu
```

Od wersji 2.1.268 zmiany zrobione w menu `/plugin` działają od razu po jego zamknięciu, bez `/reload-plugins` ([lista zmian](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)). Z shella zainstalujesz plugin komendą `claude plugin install <name>@<marketplace>`, a listę zainstalowanych zobaczysz przez `claude plugin list`. Autorom pluginów przydadzą się flagi `--plugin-dir ./my-plugin` (wczytuje plugin z folderu na jedną sesję) i `--plugin-url` (pobiera plugin w archiwum `.zip` z adresu URL).

:::caution[Obszar eksperymentalny]
Ekosystem skilli i pluginów rozwija się bardzo szybko - składnia i pola frontmattera mogą się zmieniać. Weryfikuj w [dokumentacji Agent Skills](https://code.claude.com/docs/en/skills).
:::

## Ćwiczenie: 10 minut

1. Utwórz plik `~/.claude/skills/commit-style/SKILL.md`.
2. Opisz w nim styl commitów, którego używasz w swoich projektach.
3. Sprawdź, że skill pojawia się na liście `/skills`.

**Zaliczenie:** skill jest na liście, a po jego wywołaniu Claude pisze commit w Twoim stylu bez przypominania. Jeden plik zastąpił powtarzalną instrukcję.

**Jeśli nic nie zgrzyta i zostaje czas:** dodaj do skilla plik `REFERENCE.md` z przykładami i sprawdź w `/context`, że nie ładuje się, dopóki nie jest potrzebny.

## Teraz wiesz

- Skill ładuje się progresywnie, więc dziesięć skilli nie kosztuje dziesięciu razy tyle kontekstu.
- Skill dokłada wiedzę do Twojego okna, subagent pracuje w swoim - to jedyne kryterium, które trzeba pamiętać.
- Plugin pakuje wszystko naraz, a marketplace to katalog gotowych paczek.

**Następny krok:** [Praca z Gitem i GitHubem](/claude-code/git-i-github/) - commity, pull requesty, przeglądy kodu i Claude w GitHub Actions.
