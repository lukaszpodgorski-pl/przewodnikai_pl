## Czego się tu nauczysz

Cały pozostały kurs jest o tym, jak rozmawiać z AI w oknie czatu. Ta sekcja jest o czymś innym: o narzędziu, które <Termin id="agent-ai">działa</Termin> zamiast tylko odpowiadać. Claude Code to program uruchamiany w terminalu, który czyta i zmienia pliki na Twoim dysku, uruchamia komendy, tworzy commity i podłącza się do zewnętrznych usług.

Przechodzisz przez to po kolei: instalacja, logowanie, pierwsza sesja, skróty klawiszowe. Potem rzeczy, które robią różnicę między zabawką a narzędziem pracy - plik `CLAUDE.md` z pamięcią projektu, system uprawnień, własne komendy. Na końcu zaawansowane: subagenci, hooks, MCP, tryb bez interfejsu do automatyzacji i CI, oraz zarządzanie kosztami.

## Dla kogo to jest

Dla osób średnio zaawansowanych. Nie musisz umieć programować, ale musisz być gotowy pracować w terminalu i mieć projekt, na którym da się ćwiczyć - repozytorium z kodem, katalog z dokumentami, cokolwiek, co ma strukturę plików.

Jeśli terminal jest dla Ciebie nowością, a chcesz tylko zobaczyć, o co chodzi z agentami: zacznij od Asystentów agentowych w sekcji Narzędzia, a tu wróć później.

## Jak korzystać z tego kursu

Każda lekcja kończy się **ćwiczeniem**. Terminy, komendy, flagi i nazwy plików zostają po angielsku - tak wyglądają w dokumentacji i w samym narzędziu, więc tłumaczenie ich tylko utrudniłoby Ci szukanie pomocy. Znak `~` oznacza katalog domowy użytkownika.

Fragmenty oznaczone <Badge text="NOWE" variant="tip" /> to zmiany świeższe niż główny korpus kursu. Jeśli Twoja wersja Claude Code jest starsza, mogą jeszcze nie działać.

:::caution[Stan na 30 sierpnia 2026, Claude Code 2.1.x]
Funkcje oznaczone jako nowe mogą się jeszcze zmieniać. Zanim oprzesz na czymś proces, zweryfikuj w `claude --help`, `/help` i [dokumentacji Anthropic](https://docs.claude.com/en/docs/claude-code/overview).
:::

## Czego nie ma w tej sekcji

Nie ma tu nauki programowania ani kursu Gita - zakładam, że commit i branch to dla Ciebie znane słowa. Nie ma też porównania Claude Code z konkurencyjnymi narzędziami. To kurs jednego narzędzia, nie ranking.
