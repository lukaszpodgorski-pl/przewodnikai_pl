## Program, nie okno czatu

Claude Code to program Anthropic, który działa w terminalu - oknie, w którym wydajesz komputerowi polecenia tekstem zamiast klikać. Fachowo to narzędzie CLI (command-line interface, interfejs wiersza poleceń).

Claude Code nie tylko odpowiada, ale też wykonuje realne działania na Twoim komputerze. Czyta i edytuje pliki, uruchamia komendy w terminalu, zapisuje zmiany w historii projektu (commity w Gicie) i otwiera prośby o włączenie zmian (pull requesty, w skrócie PR-y). Łączy się też z zewnętrznymi usługami przez MCP (Model Context Protocol - standard podłączania narzędzi do AI).

Jedna rzecz do zapamiętania: **czat proponuje, Claude Code robi.** Cała reszta tej sekcji, a zwłaszcza lekcja o uprawnieniach, wynika z tego jednego zdania.

## Czym różni się od innych sposobów korzystania z Claude

- **Claude.ai i aplikacja mobilna** - okno czatu: Claude pisze odpowiedź, a Ty decydujesz, co z nią zrobić. Claude Code sam _działa_ w Twoim projekcie.
- **Aplikacja desktop** - ma zakładki Chat, Cowork i Code. W zakładce Code działa Claude Code, tylko z graficznym interfejsem zamiast terminala.
- **Rozszerzenia do edytorów kodu (VS Code, JetBrains)** - nakładki na ten sam silnik Claude Code. Rdzeniem jest program terminalowy.
- **Proste programy, które tylko wysyłają pytania do API** - Claude Code to coś więcej: pełny <Termin id="agent-ai">agent</Termin>, czyli program, który sam wybiera narzędzia i wykonuje kolejne kroki. Ma przy tym pamięć projektu i system uprawnień.

## Agentowa pętla

Claude dostaje Twoje polecenie i układa plan. Potem sięga po narzędzia - na przykład Read (czytanie pliku), Edit (edycja) albo Bash (uruchomienie komendy) - i sprawdza, co z tego wyszło. Na tej podstawie wybiera następny krok i powtarza to, aż zadanie jest gotowe.

Kluczowym zasobem jest <Termin id="okno-kontekstowe">okno kontekstu</Termin>, czyli ilość tekstu, którą model widzi naraz w jednej rozmowie: Twoje polecenia, przeczytane pliki i wyniki komend. Gdy się zapełnia, najstarsze fragmenty przestają być widoczne albo zostają streszczone, a jakość pracy spada - dlatego zarządzanie kontekstem dostało w tym kursie [osobną lekcję](/claude-code/kontekst-i-koszty/).

## Modele (stan listopad 2026)

Claude Code pozwala wybrać jedną z czterech rodzin modeli: **Opus** do złożonych zadań wymagających rozumowania, **Sonnet** do codziennej pracy, **Haiku** - szybki, do prostych zadań, i **Fable** - do najtrudniejszych, długich zadań.

Zamiast pełnej nazwy wpisujesz krótki alias: `opus`, `sonnet`, `haiku` albo `fable`. Claude Code sam podstawia pod niego aktualną wersję. Są też aliasy specjalne: `best` (Fable, a tam, gdzie go nie ma - Opus), `opusplan` (Opus planuje, Sonnet wykonuje), `sonnet[1m]` i `opus[1m]`. Pełne identyfikatory to dziś `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5` i `claude-fable-5-1`.

Na planach Pro, Max, Ultra, Team, Enterprise i przy rozliczeniu przez API domyślny jest **Opus 5.5** ([konfiguracja modeli](https://code.claude.com/docs/en/model-config#default-model-setting)). Na Microsoft Foundry domyślny jest Sonnet 4.5. Fable nie jest domyślny nigdzie - włączasz go komendą `/model fable`, a zanim jego użycie zacznie zużywać dodatkowe kredyty, Claude Code zapyta o zgodę.

Model zmienisz komendą `/model` w trakcie sesji, flagą `--model` przy starcie, zmienną `ANTHROPIC_MODEL`, polem `model` w pliku ustawień (settings) albo zmienną `ANTHROPIC_DEFAULT_MODEL` dla nowych sesji.

Opus 5.5 wymaga Claude Code v2.1.280 lub nowszego, Sonnet 5.5 - v2.1.284. U dostawców chmurowych aliasy rozwijają się inaczej: na Amazon Bedrock i Google Cloud Agent Platform `sonnet` to Sonnet 4.5.

## Ćwiczenie: 5 minut

1. Uruchom `claude` w katalogu dowolnego projektu.
2. Zapytaj: "opisz strukturę tego projektu".
3. Obserwuj, jakie narzędzia Claude wywołuje - zobaczysz nazwy takie jak Read i Bash, a na Windowsie także Grep i Glob. Na macOS, Linuksie i w WSL Claude szuka plików komendami `find` i `grep` uruchamianymi przez Bash ([lista narzędzi](https://code.claude.com/docs/en/tools-reference#glob-tool-behavior)).

**Zaliczenie:** masz na kartce nazwy narzędzi, które Claude wywołał, żeby odpowiedzieć na jedno zdanie. To jest agentowa pętla w praktyce, nie metafora.

**Jeśli nic nie zgrzyta i zostaje czas:** zapytaj o coś, czego w projekcie nie ma ("gdzie jest konfiguracja płatności?"). Zobaczysz, jak Claude szuka i jak przyznaje, że czegoś nie znalazł.

## Teraz wiesz

- Claude Code to program, który zmienia pliki, a nie czat, który podpowiada.
- Pętla to plan → narzędzie → obserwacja → następny krok, aż do końca zadania.
- Model zmieniasz sam, a domyślny zależy od tego, przez kogo korzystasz z Claude: bezpośrednio przez Anthropic czy przez chmurę Amazon, Google albo Microsoft.

**Następny krok:** [Wymagania i instalacja](/claude-code/instalacja/) - pięć metod instalacji, a przy Windowsie dodatkowo decyzja natywnie czy w WSL2.
