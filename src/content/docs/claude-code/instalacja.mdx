## Wymagania

macOS 13.0+, Windows 10 1809+ albo Server 2019+, Ubuntu 20.04+, Debian 10+, Alpine 3.19+. Do tego 4 GB+ RAM, procesor x64 lub ARM64, połączenie z internetem i powłoka terminala (shell): Bash, Zsh, PowerShell albo CMD.

GPU nie jest potrzebne - model liczy się po stronie Anthropic, nie u Ciebie. `ripgrep` (program do szybkiego przeszukiwania plików) zwykle jest dołączony.

## Metoda 1 - natywny installer (zalecana)

Bez Node.js (środowiska do uruchamiania programów w JavaScripcie), z automatyczną aktualizacją.

```bash
# macOS, Linux, WSL:
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell
# Windows PowerShell:
irm https://claude.ai/install.ps1 | iex
```

```bat
:: Windows CMD:
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

Natywne instalacje aktualizują się w tle. Binarka trafia do `~/.local/bin/claude` (symlink do `~/.local/share/claude/versions/`). Instalacja konkretnej wersji: `curl -fsSL https://claude.ai/install.sh | bash -s 2.1.89` albo `stable`.

**Od wersji 2.1.243** binarka jest skompresowana (format zstd): pobranie i auto-update to ok. **75 MB zamiast 340 MB** (mierzone na Linux x64). Kod ładuje się na żądanie zamiast cały naraz, co oszczędza ok. **40-70 MB RAM w każdej sesji**.

## Metoda 2 - Homebrew (macOS, Linux)

```bash
brew install --cask claude-code          # kanał stable (~tydzień opóźnienia)
brew install --cask claude-code@latest   # kanał latest
```

Homebrew domyślnie **nie** aktualizuje automatycznie: `brew upgrade claude-code` (albo `brew upgrade claude-code@latest`, jeśli wybierasz kanał latest). Na Homebrew i WinGet możesz to zmienić zmienną `CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE=1` - wtedy Claude Code sam uruchamia aktualizację w tle ([dokumentacja instalacji](https://code.claude.com/docs/en/setup#auto-updates)).

## Metoda 3 - WinGet (Windows)

```powershell
winget install Anthropic.ClaudeCode
winget upgrade Anthropic.ClaudeCode   # manualny update
```

## Metoda 4 - menedżery pakietów Linux (apt, dnf, apk)

Dostępne są podpisane repozytoria dla apt (Debian, Ubuntu), dnf (Fedora, RHEL) i apk (Alpine). Konfiguracja to kilka komend z `sudo` - skopiuj je z [dokumentacji instalacji](https://code.claude.com/docs/en/setup#install-with-linux-package-managers). Klucz podpisujący ma fingerprint `31DDDE24DDFAB679F42D7BD2BAA929FF1A7ECACE` - dokumentacja mówi wprost, że taki właśnie odcisk powinien wypisać `gpg`. Brak lub zły klucz daje błąd przy `apt update`: `NO_PUBKEY BAA929FF1A7ECACE`. Aktualizacja przebiega przez normalny system pakietów.

## Metoda 5 - npm (legacy)

```bash
npm install -g @anthropic-ai/claude-code
npm install -g @anthropic-ai/claude-code@latest   # upgrade - NIE npm update -g
```

Wymaga **Node.js 22+** (od v2.1.198). Na starszym Node pojawi się ostrzeżenie `EBADENGINE`, ale binarka i tak zadziała, bo npm pobiera natywny plik binarny przez optional dependency.

:::danger[Nigdy sudo]
**Nigdy nie używaj `sudo npm install -g`.** To źródło trwałych problemów z uprawnieniami, które później trudno rozplątać.
:::

## Windows: natywny czy WSL2

- **Native Windows** - dla projektów Windows. Opcjonalnie zainstaluj **Git for Windows** - Claude będzie wtedy uruchamiał komendy w Git Bash, a bez niego używa PowerShella. Ścieżkę Git Bash ustawisz w settings przez `CLAUDE_CODE_GIT_BASH_PATH`.
- **WSL2** - zalecane dla pełnej zgodności z Linuksem i sandboxingu. Uruchom instalator Linux _wewnątrz_ WSL (nie instaluj binarki Windows do WSL). Trzymaj repo w systemie plików Linuksa - operacje na `/mnt/c/...` są zauważalnie wolniejsze.
- **Alpine i musl:** `apk add bash curl libgcc libstdc++ ripgrep`, potem ustaw `USE_BUILTIN_RIPGREP=0`.

## Weryfikacja, diagnostyka, aktualizacja

```bash
claude --version           # np. 2.1.224 (Claude Code)
claude doctor              # diagnostyka instalacji i settings (read-only)
claude update              # manualny update natywnej instalacji
claude install stable      # instalacja/reinstalacja kanału lub wersji
```

**Migracja z npm na natywną:** uruchom natywny installer (metoda 1) albo z shella `claude install`, a potem odinstaluj pakiet npm ([rozwiązywanie problemów z instalacją](https://code.claude.com/docs/en/troubleshoot-install)). Najczęstszy problem po migracji to stara binarka npm "zasłaniająca" natywną na PATH:

```bash
npm uninstall -g @anthropic-ai/claude-code
hash -r                    # bash; w zsh: rehash
which claude               # powinno zwrócić ~/.local/bin/claude
claude doctor              # potwierdź install type = 'native'
```

**Typowe błędy instalacji:**

- `command not found` → PATH (lista katalogów, w których system szuka programów) nie odświeżony, zrestartuj terminal.
- npm `EACCES` → napraw katalog globalny npm, nie używaj `sudo`.
- Konflikt dwóch instalacji → `which -a claude` (macOS, Linux) albo `where.exe claude` (Windows).
- Zarządzanie przez asdf → shim może wskazywać starą wersję.

**Deinstalacja (natywna):**

```bash
rm -f ~/.local/bin/claude
rm -rf ~/.local/share/claude
```

```powershell
# Windows PowerShell:
Remove-Item -Path "$env:USERPROFILE\.local\bin\claude.exe" -Force
Remove-Item -Path "$env:USERPROFILE\.local\share\claude" -Recurse -Force
```

Konfigurację usuwa `rm -rf ~/.claude` plus `rm ~/.claude.json`. Uwaga: to kasuje settings, MCP i historię. Rozszerzenie VS Code, plugin JetBrains i aplikacja desktop też zapisują do `~/.claude/` - jeśli ich nie odinstalujesz, katalog pojawi się znowu. Wyłączenie auto-update: `DISABLE_AUTOUPDATER=1` w sekcji `env` w settings.json.

Wersje v2.1.242 i v2.1.243 wywalały się przy starcie na dystrybucjach z glibc 2.44 (Arch, CachyOS, Fedora Rawhide). Naprawiono to **od wersji 2.1.245** - jeśli masz starszą, zaktualizuj.

## Ćwiczenie: 10 minut

1. Zainstaluj Claude Code preferowaną metodą - domyślnie natywnym installerem.
2. Uruchom `claude doctor`.
3. Zapisz, jaki masz "install type".

**Zaliczenie:** `claude doctor` kończy się bez błędu, a Ty wiesz, czy masz instalację `native`, czy jakąś inną. Jeśli inną, wiesz też, czy chcesz migrować.

**Jeśli nic nie zgrzyta i zostaje czas:** sprawdź `claude --version` i porównaj z wersją, przy której opisane są nowości w tej sekcji. Zobaczysz od razu, które fragmenty kursu Cię jeszcze nie dotyczą.

## Teraz wiesz

- Natywny installer to domyślny wybór: bez Node.js i z aktualizacją w tle.
- Na Windowsie decyzja natywnie czy WSL2 zapada raz i wpływa na wydajność.
- `claude doctor` jest pierwszą komendą przy każdym problemie z instalacją.
