Claude Code świetnie radzi sobie z gitem. Siedem typowych workflow:

- **Commity** - poproś "zrób commit z opisową wiadomością", albo użyj własnej komendy `/commit` z lekcji o [własnych komendach](/claude-code/wlasne-komendy/). Commituj często: co zadanie albo co godzinę.
- **Pull requesty** - "utwórz PR z tytułem i podsumowaniem w trzech punktach". Claude użyje `gh` CLI.
- **Konflikty** - "rozwiąż konflikty merge w tych plikach". Claude czyta i proponuje rozwiązanie.
- **Przegląd** - `/code-review` (alias `/review`) znajduje bugi i cleanup w bieżącym diffie. `--fix` aplikuje poprawki, `--comment` dodaje komentarze do PR, `ultra` uruchamia głęboki review w chmurze. `/security-review` szuka podatności.
- **`gh` CLI** - wymagany do statusu PR w stopce i wielu operacji GitHub. Uwierzytelnij przez `gh auth login`. Odpowiednik dla GitLaba to `glab`.
- **GitHub Actions** - `/install-github-app` instaluje aplikację Claude GitHub i konfiguruje workflow. Potem tagujesz `@claude` w komentarzach PR i issue, żeby Claude działał w CI.
- **Git worktrees** - `claude -w feature-auth` daje izolowany worktree do równoległych sesji, `--tmux` tworzy panel tmux, a subagent z `isolation: worktree` dostaje izolowaną kopię repozytorium.

## Ćwiczenie: 10 minut

1. Na gałęzi z małą zmianą uruchom `/diff`.
2. Uruchom `/code-review` i przeczytaj znalezione uwagi.
3. Poproś Claude o commit z opisową wiadomością.

**Zaliczenie:** masz commit, którego wiadomości nie musiałeś pisać, i listę uwag, których sam nie szukałeś. Oceń, ile z nich było trafnych - to Twój punkt odniesienia na przyszłość.

**Jeśli nic nie zgrzyta i zostaje czas:** uruchom `/code-review --fix` na tej samej gałęzi i porównaj, co narzędzie zmieniło samo, a co zostawiło Tobie.

## Teraz wiesz

- Commity, pull requesty i konflikty to zadania, które oddajesz w całości.
- `gh` CLI jest wymagane, a nie opcjonalne, jeśli pracujesz z GitHubem.
- Worktree to sposób na kilka równoległych sesji bez deptania sobie po gałęziach.

**Następny krok:** [Terminal, IDE i urządzenia](/claude-code/terminal-ide-urzadzenia/) - konfiguracja terminala, wtyczki do edytorów i przenoszenie sesji między urządzeniami.
